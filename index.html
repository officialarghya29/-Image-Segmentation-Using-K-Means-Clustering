IPA Project

Project name — Image Segmentation Using K-Means Clustering

This project takes any photograph and reduces it to a handful of representative colours by clustering its pixels with K-Means. The clustering itself runs on a Python (Flask) backend — the browser only uploads the image and displays whatever the backend computes: the segmented image, a grid overlay, a cluster colour legend, quantisation-error statistics, and an elbow graph for choosing a good value of k.

What this project does

Every pixel of an image is treated as a point in RGB colour space. The uploaded image is sent to a Flask backend, where main.py runs K-Means to group those points into k clusters, then repaints each pixel with its cluster's average colour — producing a simplified, posterised version of the image, plus the statistics behind that simplification.

Quick facts

Python backend
All clustering runs server-side in main.py via NumPy
k-means++
Smarter centroid initialisation than random picks
RGB space
Clustering is done on normalised 0–1 colour values
Adjustable grid
Overlay spacing is fully configurable, values-free
